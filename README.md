# Голосовой ассистент (chatBOT)

Полностью локальный голосовой ассистент с текстовым интерфейсом (TUI). Распознавание речи — Vosk, генерация ответов — локальная LLM через llama.cpp (GGUF). Интернет не требуется, данные никуда не отправляются.

## Принцип работы

1. Микрофон захватывается через `sounddevice` (16 кГц, моно), аудио идёт в очередь.
2. Vosk распознаёт речь и выдаёт промежуточный, затем финальный текст.
3. Финальная фраза сначала проверяется по списку голосовых команд (JSON): при совпадении запускается указанная программа.
4. Если команда не сработала — фраза отправляется в локальную LLM (при включённом auto-send автоматически, иначе по кнопке Send).
5. LLM получает системный промпт, историю последних N пар сообщений и генерирует ответ.
6. Ответ выводится в чат; распознанный текст и статусы показываются в интерфейсе.
7. Если включена озвучка, ответ синтезируется локально (Piper TTS) и воспроизводится через динамики.

Всё тяжёлое (загрузка моделей, генерация, запись) выполняется в фоновых потоках, интерфейс не блокируется.

## Возможности

- **Чат в TUI** (Textual): вкладки Chat и Settings, тёмная тема, ввод текста или голосом.
- **Локальная LLM**: файлы GGUF через `llama-cpp-python`; поддержка CUDA-оффлоада слоёв на GPU (`llm_gpu_layers`), контекст, температура, лимит токенов и системный промпт настраиваются.
- **Память диалога**: LLM помнит последние пары «вопрос–ответ» (число пар настраивается, 0 — не помнить).
- **Распознавание речи**: любая распакованная модель Vosk, выбор микрофона, отображение промежуточного результата.
- **Голосовые команды**: фразы-триггеры запускают программы. Запуск без shell (`subprocess.Popen` + `shlex`), команды хранятся в JSON.
- **Озвучка ответов (TTS)**: локальный синтез Piper — голоса `.onnx`, можно выключить, выбрать голос, проверить его и прервать воспроизведение.
- **Настройки**: сохраняются в `~/.config/voice-assistant/config.json`, есть встроенный выбор файлов/каталогов.
- **Горячие клавиши**: `Ctrl+C` — выход, `Ctrl+L` — очистить чат, `Ctrl+1` / `Ctrl+2` — вкладки.

## Установка

```bash
git clone <репозиторий>
cd chatBOT
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### Сборка llama-cpp-python под CUDA (для работы на GPU)

Нужны CUDA toolkit и ninja. Пример для Arch Linux:

```bash
sudo pacman -S cuda ninja
```

Пересборка с поддержкой CUDA (архитектура указывается под вашу видеокарту, 86 — RTX 30xx):

```bash
PATH=/opt/cuda/bin:$PATH CUDACXX=/opt/cuda/bin/nvcc \
CMAKE_ARGS="-DGGML_CUDA=on -DCMAKE_CUDA_ARCHITECTURES=86" \
.venv/bin/pip install --force-reinstall --no-cache-dir --no-binary llama-cpp-python llama-cpp-python==0.3.36
```

Без CUDA проект работает на CPU (просто будет медленнее), `llm_gpu_layers` при этом игнорируется.

### Модели

- **Vosk**: скачать и распаковать модель (например, `vosk-model-ru-0.42`), в настройках указать каталог.
- **LLM**: скачать GGUF-файл (например, Qwen3-14B-Q6_K.gguf), в настройках указать файл.
- **Голос Piper**: скачать `.onnx` + `.onnx.json` (например, `python -m piper.download_voices ru_RU-irina-medium` или с huggingface.co/rhasspy/piper-voices), в настройках указать `.onnx`-файл.

## Запуск

```bash
.venv/bin/python chat.py
```

В настройках (Ctrl+2) выбрать каталог Vosk, микрофон, GGUF-файл; при необходимости задать число слоёв на GPU и нажать «Загрузить LLM». Кнопка Mic включает прослушивание.

## Настройки (config.json)

| Ключ | Описание | По умолчанию |
|------|----------|--------------|
| `vosk_model_path` | Каталог распакованной модели Vosk | — |
| `microphone` | Имя или индекс устройства записи | `default` |
| `auto_send` | Автоматически отправлять распознанную фразу в LLM | `true` |
| `memory_pairs` | Сколько пар «вопрос–ответ» помнит LLM (0–50) | `3` |
| `llm_model_path` | Путь к файлу модели `.gguf` | — |
| `llm_context_size` | Размер контекста `n_ctx` | `4096` |
| `llm_temperature` | Температура генерации (0–2) | `0.7` |
| `llm_max_tokens` | Максимум новых токенов | `512` |
| `llm_gpu_layers` | Сколько слоёв выгружать на GPU (0 — только CPU) | `20` |
| `disable_thinking` | Отключить блок размышлений (`<think>`) у моделей вроде Qwen3 | `true` |
| `tts_enabled` | Озвучивать ответы модели | `true` |
| `tts_model_path` | Путь к голосовой модели Piper (`.onnx`) | — |
| `tts_output_device` | Устройство вывода: `auto` — системное через сервер звука, иначе имя устройства | `auto` |
| `tts_volume` | Громкость озвучки в процентах (0–100) | `100` |
| `system_prompt` | Системная инструкция для LLM | — |
| `voice_commands` | JSON-список голосовых команд: `phrases`, `command`, `description` | Firefox, Telegram |

## Структура

- `chat.py` — приложение целиком: интерфейс, настройки, воркеры STT/LLM/TTS, выполнение команд.
- `styles.tcss` — стили Textual.
- `requirements.txt` — зависимости: textual, sounddevice, vosk, llama-cpp-python, piper-tts.
